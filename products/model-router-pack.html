Model Router Field Guide: 10 Prompts for Routing Work Across Models

Ten prompts for designing, testing and debugging a router that sends AI work across several models and providers, taken from a router that runs scheduled work every day.

What's inside

Most model-router advice is a table of which model is smartest. The hard part is what happens when the first model in your list is out of quota, the second was removed by its provider, and a timeout on one huge prompt has made your router avoid every small one.

This guide covers that part. It is written from a router that runs real scheduled work every day: a task-type ladder, a resolver that reorders the ladder by what each provider last reported, and a shared cooldown table.

The 10 prompts, one job each:

  • 1 · Task-type inventory: turn a pile of AI calls into a few task types
  • 2 · Ladder builder: the ordered model list per task type
  • 3 · Error classifier: decide what a provider error means
  • 4 · Reorder-never-drop policy: fallbacks that reorder instead of disappear
  • 5 · Sensitive-route filter: keep confidential input off training routes
  • 6 · Size-aware cooldown: stop one big timeout from banning small prompts
  • 7 · Head-to-head on your tasks: compare models on your own work, blind
  • 8 · Routing log reader: a week of routing logs in five minutes
  • 9 · Model-id freshness check: catch ids a provider has removed
  • 10 · Routing incident review: write up a failure so it stays fixed

Every prompt has four lines: When, Expected output, Failure mode and Tip. The worked example is a real run of the router's own resolver code on a five-route test registry under a simulated outage, plus live calls with their real latency, shown as they came back. It ends with lessons from real routing incidents and a list of free resources.

What this is not: a hosted router, an SDK or software you install, or a ranking of the best model (that changes monthly). It does not promise that any free tier stays free or that a model id named in it still exists when you read it.
